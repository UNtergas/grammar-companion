# Resources

Read what the current milestone needs, not everything up front.

## Rust — core

- The Rust Book — https://doc.rust-lang.org/book/
  - M0: ch. 1, ch. 7 (packages, crates, modules), ch. 14.3 (workspaces)
  - M1: ch. 4 (ownership), ch. 6 (enums), ch. 8.2 (strings and UTF-8), ch. 9 (errors), ch. 10 (traits), ch. 11 (tests)
  - M2: ch. 16 (concurrency), ch. 17 (async)
- Rust by Example — https://doc.rust-lang.org/rust-by-example/
- Rustlings (small exercises, good in parallel with M0–M1) — https://github.com/rust-lang/rustlings

## Rust — service layer (M2+)

- Tokio tutorial — https://tokio.rs/tokio/tutorial
- Serde — https://serde.rs/
- *Zero To Production in Rust* (Luca Palmieri) — backend practices in Rust (book)

## Grammar engines (M1)

- Harper (Rust, English only) — https://writewithharper.com/ · crate: https://crates.io/crates/harper-core
- LanguageTool embedded HTTP server — https://dev.languagetool.org/http-server.html

## Browser (M2–M3)

- Chrome native messaging — https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging
- MDN WebExtensions native messaging (Firefox) — https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Native_messaging

## Local models (M4)

- llama.cpp — https://github.com/ggml-org/llama.cpp
- Candle (Rust ML framework) — https://github.com/huggingface/candle
- Ollama — https://github.com/ollama/ollama

## Later

- *Rust for Rustaceans* (Jon Gjengset) — after M2, when the basics feel boring
- "Crust of Rust" videos (Jon Gjengset) — deep dives on specific std features
